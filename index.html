EXPERIMENT 01

1. Fibonacci Series

Generate and store the first 10 Fibonacci numbers.

Simple logic: Start with 0 and 1. Add the two values, shift the values forward, store the current term, and repeat 10 times.

Complete program

AREA FIBO, CODE, READONLY
EXPORT __main
__main
ENTRY
START
    LDR R4, =RESULT
    MOV R0, #0
    MOV R1, #1
    MOV R2, #10
LOOP
    STR R0, [R4], #4
    ADD R3, R0, R1
    MOV R0, R1
    MOV R1, R3
    SUBS R2, R2, #1
    BNE LOOP
STOP
    B STOP
AREA DATA, DATA, READWRITE
RESULT SPACE 40
END

EXPERIMENT 02

2. Addition of 16-bit Array

Add six 16-bit values and store the sum as a 32-bit result.

Simple logic: R1 points to the array. LDRH loads one 16-bit halfword (2 bytes). R4 holds the running sum and R5 counts the six elements.

Complete program

EXPORT __main
__main
ENTRY
START
    MOV R5, #6
    MOV R4, #0
    LDR R1, =VALUE1
LOOP

    ADD R4, R0, R4
    SUBS R5, R5, #1
    CMP R5, #0
    BNE LOOP
    LDR R0, =RESULT
    STR R4, [R0]
    NOP
VALUE1
    DCW 0x1111, 0x2222, 0x3333
    DCW 0xAAAA, 0xBBBB, 0xCCCC
AREA DATA1, DATA, READWRITE
RESULT DCD 0
END

5. Ascending Order (Notebook Version)

Copy six 32-bit values to RESULT, then repeatedly compare adjacent values and swap when the left value is greater.

Simple logic: R5 points to the input VALUE array. R0 points to RESULT. The COPY loop copies six words. The OUTLOOP and INLOOP perform bubble-sort passes. CMP compares adjacent values; BLS skips the swap when the left value is already lower or equal.

Complete program

AREA ASCENDING, CODE, READONLY
EXPORT __main
ENTRY
__main
START
    LDR R5, =VALUE
    LDR R0, =RESULT
    MOV R6, #6
COPY
    LDR R2, [R5], #4
    STR R2, [R0], #4
    SUBS R6, R6, #1
    BNE COPY
    MOV R1, #5
OUTLOOP
    LDR R0, =RESULT
    MOV R3, R1
INLOOP
    LDR R2, [R0]
    LDR R4, [R0, #4]
    CMP R2, R4
    BLS SKIP
    STR R4, [R0]
    STR R2, [R0, #4]
SKIP
    ADD R0, R0, #4
    SUBS R3, R3, #1
    BNE INLOOP
    SUBS R1, R1, #1
    BNE OUTLOOP
    NOP
VALUE
    DCD 0x44444444, 0x22222222, 0x11111111
    DCD 0xAAAAAAAA, 0x33333333, 0x88888888
AREA MYDATA, DATA, READWRITE
RESULT DCD 0, 0, 0, 0, 0, 0

EXPERIMENT 05

7. Count 1s and 0s in Two Consecutive Memory Locations

Count the number of set bits (1s) and clear bits (0s) in two 32-bit words.

Simple logic: R2 counts zero bits and R3 counts one bits. R7 is the number of bits to inspect in each word (32). R6 points to VALUE. LDR reads each word. MOVS with ROR #1 rotates the least significant bit into the carry flag; BHI ONES is used in the notebook to test the bit path. The counters are incremented and the loops repeat.

Complete program

AREA ONEZERO, CODE, READONLY
EXPORT __main
ENTRY
__main
START
    MOV R2, #0
    MOV R3, #0
    MOV R7, #2
    LDR R6, =VALUE
LOOP
    MOV R1, #32
    LDR R0, [R6], #4
LOOP0
    MOVS R0, R0, ROR #1
    BHI ONES
    ADD R3, R3, #1
    B LOOP1
ONES
    ADD R2, R2, #1
LOOP1
    SUBS R1, R1, #1
    BNE LOOP0
    SUBS R7, R7, #1
    CMP R7, #0
    BNE LOOP
    NOP
VALUE
    DCD 0x11111111, 0xAA55AA55
AREA DATA, DATA, READWRITE
END

8. Count Odd and Even Numbers in an Array

Count odd and even numbers in the six-element array from the printed lab manual.

Simple logic: R2 stores the even count and R3 stores the odd count. R7 is loaded with ARRAYLEN (6). Each word is loaded into R0. TST R0,#1 checks bit 0: if it is zero, the number is even; otherwise it is odd.
